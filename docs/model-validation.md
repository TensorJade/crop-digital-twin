# 模型与遥感验证计划

首版面向华南水稻，具体县市、品种参数和实测数据尚待确定。PCSE 6.0.13 的 Wofost72_PP 已通过输入、单位、执行和导出检查，目前仅支持直播出苗后的潜在生长，假定水肥充足。`agronomically_validated=false`，`management_effects_applied=false`，当地验证及移栽水田适配仍需完成。

## 验证资料

| 内容 | 所需资料 |
|---|---|
| 品种与物候 | 品种参数、播种/出苗/移栽日期、实测物候 |
| 生长与产量 | 地块 LAI、生物量、产量及测量方法 |
| 天气 | 当地站点或田间观测、变量单位、日界及缺测情况 |
| 水田管理 | 灌排过程、水分条件、施肥成分和用量 |
| 无人机影像 | 传感器、波段、定标材料、拍摄时间、坐标、正射和光照质量 |

品种参数、数据来源和使用许可在验证前核对。当前合成 LAI 曲线用于软件检查，农艺评价使用独立实测资料。

## 遥感处理与模型更新

影像先完成辐射定标和质控，得到反射率后再计算指数、覆盖度和 LAI。RGB 或处理级别不明的 TIFF 需先明确数据含义，不能直接作为反射率输入。

模型更新需记录观测误差、空间匹配、可辨识参数及约束，保存原预测、观测和更新版本。初期采用离线、可复现的有界校准，检查历史回放。

## 评价方法

按地块、种植季或年份划分独立验证集，对比模型原预测、遥感估计和更新后预测，报告 RMSE、偏差、不确定性及缺测、异常输入表现。验收阈值在试点资料确定后制定。

NASA 历史天气由小时值按北京时间汇总，网格海拔和温度极值可能与田间或站点观测不同，需要评估当地偏差。公网请求检查已通过，授权站点观测和试点天气验证尚待完成；目录覆盖日期仅供检索。
