# 模型与遥感验证门槛

本仓库当前没有农艺验证结果。接入 PCSE/WOFOST 时先限定作物、地区、生产水平和土壤水分方案，核对品种参数、天气单位、管理事件和模型许可，再用实测物候、LAI、生物量及产量验证。

无人机多光谱输入应包括传感器/波段信息、辐射定标材料、拍摄时间、位置/坐标、正射及光照质量信息。先从原始观测得到有来源的反射率和质量标记，才计算光谱指数及长势反演。不能将 RGB 或未知处理级别的 TIFF 直接当作可靠反射率。

遥感更新需要观测误差、空间匹配、可辨识参数/状态和边界约束；不允许任意覆盖所有模型状态。保留未校准预测、观测及更新后版本，验证可回放性。开发初期优先选择离线、可复现的有界校准流程。

以地块/季节/年份独立划分验证集，比较模型原预测、遥感单独估计与更新后预测；报告 RMSE、偏差、不确定性、缺测与异常输入表现。没有独立评估和验收阈值前，不声称提升精度或实时校准达到上线水平。
