# 模型与遥感验证门槛

本仓库当前没有农艺验证结果。首版已确认华南水稻，尚缺具体县市、品种参数和实测数据。接入 PCSE/WOFOST 时需明确生产水平、水田水分与灌排方案、移栽时间语义，核对参数、天气单位、管理事件和模型许可，再用实测物候、LAI、生物量及产量验证。

无人机多光谱输入应包括传感器/波段信息、辐射定标材料、拍摄时间、位置/坐标、正射及光照质量信息。先从原始观测得到有来源的反射率和质量标记，才计算光谱指数及长势反演。不能将 RGB 或未知处理级别的 TIFF 直接当作可靠反射率。

遥感更新需要观测误差、空间匹配、可辨识参数/状态和边界约束；不允许任意覆盖所有模型状态。保留未校准预测、观测及更新后版本，验证可回放性。开发初期优先选择离线、可复现的有界校准流程。

以地块/季节/年份独立划分验证集，比较模型原预测、遥感单独估计与更新后预测；报告 RMSE、偏差、不确定性、缺测与异常输入表现。没有独立评估和验收阈值前，不声称提升精度或实时校准达到上线水平。

M3.2已实际执行PCSE6.0.13 Wofost72_PP，软件输入/单位、模型可执行性、版本和导出测试通过；agronomically_validated仍false。模式仅直播出苗、潜在水肥充足，management_effects_applied=false；移栽/水田和独立农艺验证未完成。合成验收LAI曲线不能作为水稻精度证据。

M3.3历史网格天气按北京时间小时汇总，保留原始来源并验证完整性；网格海拔/小时温度极值与农田/站点实测可能不同，需另用当地站点或田间资料评估偏差。真实公网烟雾通过只证明接口/单位/格式，不能证明当地天气精度。站点目录候选及历史覆盖不保证当前观测可用，授权观测接口与试点验证仍待实施。
