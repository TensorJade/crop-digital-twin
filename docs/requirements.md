# 需求与实现追踪

本文件追踪实际代码状态；原始完整需求和非功能验收见 [设计基线](design-baseline/design.json)。编号按原方案 F01–F12 保留，不将保留目录当作实现。

后续每个需求需补齐用例、接口契约、权限、异常、测试证据及验收结论。实现完成并验证前状态均为“未实现”。

## 当前可验收的开发入口

- `GET /api/v1/health` 无请求体，返回进程存活、服务名、版本及 `scope=process`。未声称依赖就绪。
- 前端开发首页可经 Vite 代理调用此接口，HTTP 失败或格式不符时显示错误。
- Python/npm 依赖锁文件、静态检查和测试可从本地脚本执行。
- Git 记录源码与文档，忽略真实配置、数据、依赖、日志和备份。
