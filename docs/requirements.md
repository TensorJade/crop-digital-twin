# 需求与实现追踪

需求沿用原方案的 F01–F12 编号。总体目标和非功能要求见 [设计基线](design-baseline/design.json)，接口字段以导出的 contracts/openapi.* 为准。模块规则见 [M1](modules/farm-management.md)、[M2](modules/identity.md)、[M3.1](modules/simulation-inputs.md)、[M3.2](modules/potential-simulation.md)和 [M3.3](modules/weather-sources.md)，检查结果见 [开发日志](dev-log/README.md)。

| 编号 | 功能 | 当前可用范围 | 尚待交付 |
|---|---|---|---|
| F01 | 账户与权限 | 登录/退出/密码修改，组织隔离，管理员/农田管理/只读，成员启停，同事务操作审计 | 账号找回、逐成员地块授权、角色转移、公开部署验收 |
| F02 | 地块与种植季 | 本组织手工面积、WGS84 点、水稻直播/移栽、日期、历史季和结束操作 | 卫星圈地、边界导入、空间面积 |
| F03 | 参数配置 | 土壤登记、rice/WOFOST72 参数 JSON、来源/许可/适用区域与版本；静态完整性检查 | 经许可且当地验证的品种模板、生理合理性/当地精度 |
| F04 | 天气接入 | CSV 导入、NASA 历史天气、1–366 天分段获取、来源保存、NOAA 目录、蒸散量 | 站点观测、当天更新、预测、误差验证 |
| F05 | 农事记录 | 播种、移栽、灌溉、施肥、巡田、收获；水肥换算、追加修订、历史查询及授权审计 | 模型关联 |
| F06 | 生长模拟 | PCSE 潜在模式、任务恢复、结果版本、曲线和下载 | 移栽、水田管理、当地实测验证 |
| F07 | 影像接入 | 未实现 | 多光谱 GeoTIFF、元数据、质量报告 |
| F08 | 长势反演 | 未实现 | 指数、覆盖度、验证后的绿叶 LAI 与误差 |
| F09 | 观测校正 | 未实现 | 有界校准、先验约束、重算、版本 |
| F10 | 地图展示 | 未实现 | 卫星底图、栅格、矢量、历史回放 |
| F11 | 情景比较与提醒 | 未实现 | 同一天气假设的情景比较、风险规则 |
| F12 | 数据维护 | SQL、增量迁移、输入和结果版本、农事修订、审计、JSON 导出 | 影像、备份恢复、校准版本 |

实际验收覆盖表单到 SQL、日期/单位/历史、会话重启、跨组织越权、角色、CSRF、密码响应脱敏、启停/改密码撤销会话、并发写入、旧数据升级与审计失败回滚。测试账号只在隔离数据库建立。

GET /api/v1/health 仅表示进程存活，不证明数据库迁移或外部依赖就绪。模型精度、遥感有效性、备份恢复、生产安全和容量在对应模块另行验收。

天气按北京时间分日，要求完整小时数据，并保留来源和 SHA-256。NOAA 目录查询尚未接入站点观测；网格小时派生温度极值与站点日极值需要分别使用。只读成员可查看已有资料，获取请求在 SQL 事务结束后联网，失败不保存部分日值。接口和检查过程见 [天气模块](modules/weather-sources.md)。
