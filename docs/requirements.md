# 需求与实现追踪

按原方案 F01–F12 追踪；完整目标与非功能要求见 [设计基线](design-baseline/design.json)。实际接口由 contracts/openapi.* 导出；规则和证据见 [M1 设计](modules/farm-management.md)与 [开发日志](dev-log/2026-10-08-farm-management.md)。

| 编号 | 功能 | 当前可用范围 | 尚待交付 |
|---|---|---|---|
| F01 | 账户与权限 | 未实现 | 组织、成员、角色、地块授权、审计 |
| F02 | 地块与种植季 | 手工面积、WGS84 点、水稻直播/移栽、日期、历史季和结束操作 | 卫星圈地、边界导入、空间面积、权限 |
| F03 | 参数配置 | 仅品种名称，无模型参数 | 品种、土壤、站点模板、来源和适用范围 |
| F04 | 天气接入 | 未实现 | 授权数据源、站点匹配、质量标记 |
| F05 | 农事记录 | 播种、移栽、灌溉、施肥、巡田、收获；水肥换算、追加修订、历史查询 | 模型关联及授权审计 |
| F06 | 生长模拟 | 未实现 | PCSE 日值、版本、适用条件 |
| F07 | 影像接入 | 未实现 | 多光谱 GeoTIFF、元数据、质量报告 |
| F08 | 长势反演 | 未实现 | 指数、覆盖度、验证后的绿叶 LAI 与误差 |
| F09 | 观测校正 | 未实现 | 有界校准、先验约束、重算、版本 |
| F10 | 地图展示 | 未实现 | 卫星底图、栅格、矢量、历史回放 |
| F11 | 情景比较与提醒 | 未实现 | 同一天气假设的情景比较、风险规则 |
| F12 | 数据维护 | SQL 持久化、增量迁移、农事修订；数据库不入 Git | 资产/任务、导出、备份恢复、科学快照 |

M1 验收覆盖录入到数据库读取、日期/单位/修订/并发以及故障重试；HTTP 验证、业务错误、存储故障与生产启动边界分别检查。默认数据库重启后保留数据。无账户权限，当前仅供本地单用户试用。

GET /api/v1/health 仅表示进程存活，不证明数据库迁移或外部依赖就绪。模型精度、遥感有效性、备份恢复、安全和容量在对应模块另行验收。
