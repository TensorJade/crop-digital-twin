# 实际开发进度

更新日期：2026-10-08。首版范围：华南水稻。当前版本：0.2.0，本地单用户农田管理。

| 阶段 | 交付目标 | 当前状态 |
|---|---|---|
| S0 | 目录、Git、入口、契约、检查、日志 | 已完成开发骨架 |
| S1 | 登录权限、地块、种植季、农事、持久化 | M1 农田管理已实现并完成本地验收；M2 登录权限未开始 |
| S2 | 天气/土壤快照、PCSE、任务重算与版本 | 未开始 |
| S3 | 授权底图、地块矢量、长势与时间轴 | 未开始 |
| S4 | 无人机质控、反射率与 LAI 反演 | 未开始 |
| S5 | 有界校准、独立验证、恢复与发布验收 | 未开始 |

M1 包含前端三步流程、9 个业务操作、3 张业务表和迁移。日期、单位、历史修订、并发、重启持久化和故障重试均有实际测试。默认 SQLite 已初始化；本机 Docker 未运行，PostgreSQL 验证由 CI 独立数据库完成。验证与 Git 记录见 [M1 日志](dev-log/2026-10-08-farm-management.md)。

当前不包含地图、科学模型、天气、遥感、队列、备份或公开服务；核心覆盖率衡量软件规则，不衡量农艺有效性。代码与日志通过功能分支同步至 [远程仓库](https://github.com/TensorJade/crop-digital-twin)。

模块顺序见 [module-roadmap.md](module-roadmap.md)。下一项为 M2；M3 仍需具体县市、品种参数、来源授权、水田过程与独立验证资料。
