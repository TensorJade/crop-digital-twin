# M2 账户、组织授权与审计开发日志

## 范围与决策

按既定路线从 M1 进入 M2，首版继续华南水稻。功能分支从 release_20261008 建立，再快进接收已验证 M1（402deb0a6b329cb87ffd29f613426b69f1511bb5），不合并保护分支、不部署。实施依据：奥卡姆剃刀、高内聚低耦合，模块设计与数据流先于代码。

一个账号一个组织，组织内共享地块，管理员/农田管理/只读三种角色。无逐成员地块矩阵、公开注册、找回密码或角色转移。初始管理员交互创建，没有默认运行账号/密码。仍使用一个 API 与 SQL，不增加 Redis、JWT、权限框架或全局前端状态库。

## 代码与数据

- domain/identity、IdentityService、存储/密码 Protocol、SQL 适配和身份 API；农田查询在 SQL 层限定组织，跨组织父子资源均返回 404。
- Argon2id 哈希；32 字节随机会话只通过 HttpOnly Cookie，SQL 留摘要，固定 8 小时到期。会话绑定 CSRF，前端内存持有；退出、改密码和停用撤销相应会话。
- 登录来源失败计数落 SQL，五次/15 分钟；失败结果先提交计数再返回错误，不信任任意代理头。审计与业务同事务追加，无请求正文/凭据。
- Alembic 0002 新建组织、用户、会话、登录限制、审计五表；旧地块只增加可空归属。显式 AdoptLegacy 才接收未归属旧数据，不转移已归属地块。
- Vue 登录、成员/审计、改密码页面和农田角色控制。会话失效卸载工作区，桌面/手机共用简洁表单。
- 新增 9 个 API 操作；总计 15 条路径、19 个 GET/POST 操作，OpenAPI 0.3.0。
- 锁定 argon2-cffi 25.1.0（MIT）；Python>=3.8，实际环境 Python3.12。依赖沿官方库安装，不使用外部账户服务；uv.lock 记录传递依赖。
