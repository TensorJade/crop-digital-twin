## 修改内容

账号归属一个组织，组织内共享地块，角色分为管理员、农田管理和只读。初始管理员通过交互脚本创建。此阶段未实现公开注册、找回密码、角色转移及逐成员地块授权。

| 部分 | 实现 |
|---|---|
| 业务 | domain/identity、IdentityService、存储和密码接口 |
| 密码 | Argon2id，锁定 argon2-cffi 25.1.0（MIT） |
| 会话 | 32 字节随机令牌、HttpOnly Cookie、SQL 摘要、8 小时到期 |
| CSRF | 会话绑定令牌，前端保存在内存 |
| 登录限制 | SQL 记录来源失败次数，五次 / 15 分钟 |
| 授权 | SQL 查询限定组织，跨组织资源返回 404 |
| 审计 | 与业务同事务追加，不记录正文或凭据 |
| 前端 | 登录、成员、审计、改密码和角色控制 |

退出、改密码和成员停用会撤销相应会话。失败登录先保存计数，再返回错误。前端会话失效后卸载工作区。

Alembic 0002 新增组织、用户、会话、登录限制、审计五张表；旧地块增加可空组织字段。只有显式使用 `AdoptLegacy` 才接收未归属的旧数据，已归属地块保持原组织。新增 9 个操作，总计 15 条路径、19 个 GET/POST 操作，OpenAPI 版本 0.3.0。沿用一个 API 和 SQL，不引入 Redis、JWT 或权限框架。argon2-cffi 要求 Python >=3.8，本次使用 Python 3.12，传递依赖由 uv.lock 固定。

## 问题处理

| 问题 | 处理 |
|---|---|
| SQLAlchemy 2.1 Select 泛型标注不匹配 | 修正类型标注 |
| 非 ASCII CSRF 字符串比较报错 | 调整比较处理并增加测试 |
| 默认 422 响应回显密码输入 | 过滤原始输入 |
| 当前密码错误导致误登出 | 返回 400，保留有效会话 |
| 初始化脚本反向依赖 API | SQLite 写锁工具移到存储层 |
| Uvicorn 默认解析代理头 | 开发和验收关闭 proxy_headers |
| 旧请求的 401 清空新登录 | 根据会话代次处理延迟响应 |

代理头测试连续更换伪造 X-Forwarded-For 进行五次失败登录，第六次仍返回 429。上述修正均复查通过。
