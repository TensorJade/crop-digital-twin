## ODM 参数

```powershell
docker run --rm -it `
  -v "D:\2025_Rice_GuangDong\多光谱图像\202505_odm_verified\DJI_202505270928_019_2025增城水稻:/datasets/code" `
  opendronemap/odm:3.5.3 `
  --project-path /datasets `
  --radiometric-calibration camera `
  --fast-orthophoto --cog --build-overviews --skip-report
```

OpenDroneMap 已完成数据阶段，识别出 5 个波段并开始使用 249 张 Green 影像进行空三特征提取。它提示 RGB 与单波段影像存在冗余，自动跳过 249 张 RGB 影像作为重建波段；RGB 文件仍保留在工作目录，供任务识别和后续波段处理使用。第一次完整正射任务在稠密重建后发现点云范围异常，已停止并改用 `--fast-orthophoto`，避免在异常 DEM 范围上生成数百万瓦片。

`camera` 归一化不等于现场反射率标定。当前目录没有发现校准板照片，因此输出完成后必须标记为“未完成现场反射率校准”。
