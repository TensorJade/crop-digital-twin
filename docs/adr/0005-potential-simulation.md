# ADR0005：先运行潜在模式，计算离开 API

2026-10-08。复用 M3.1 已封存资料，加入固定 PCSE6.0.13 Wofost72_PP。不把通用土壤水量平衡宣称为已验证的水田淹水/灌排模型；首个运行模式假定水肥充足，直播出苗、北京时间逐日已发生天气，管理员须明确确认。移栽和管理响应另行适配，输入完整不代表当地农艺验证。

一个 SQL 任务/结果表、独立 worker、限时临时子进程足以支持当前需求。不引入 Redis、Celery、微服务或队列抽象平台。HTTP 只排队，事务领取/租约/完成持久化；计算期间不持有 SQL 写锁。重复请求 key 去重、每次新计算保留版本，过期任务可重领，租约令牌拒绝迟到写回。

PCSE 用户目录初始化、日志、演示库副作用必须隔离，算法进程不继承应用配置。预建临时空演示库标记避免自带表参与应用；业务 DAO 完全使用自己的三模块 SQL 模型。运行输入是内部限定结构 JSON，不读取用户 Python、YAML 或 URL。蒸散系数由来源提供，不使用隐式当地默认值。

引用：[PCSE 模型/天气官方文档](https://pcse.readthedocs.io/en/stable/code.html)、[PCSE6.0.13](https://pypi.org/project/pcse/6.0.13/)。
