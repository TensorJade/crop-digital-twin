# ADR 0002：农田管理模块

日期：2026-10-08。模块：M1。首版范围：华南水稻。

## 决定及原因

- 地块、种植季和农事放在同一模块，HTTP、业务和 SQL 分层，便于一起维护日期与修订规则。
- 使用 FarmRepository Protocol 连接 SQLite 和 PostgreSQL，共用 SQLAlchemy、Alembic，各数据库分别做集成测试。
- 使用逻辑外键，在事务中检查引用，限制删除，并约束修订指针。PostgreSQL 使用父对象行锁，SQLite 串行写入。
- ID 和关系字段使用 UUID。
- 初期保存人工面积和位置，空间计算留到地图模块。
- 农事修正时新增版本，单位换算使用纯函数。
- 前端使用局部状态和模块组件；当前不增加 Router、Pinia、Redis 或消息队列。
- 0.2.0 尚无账户，只供本地单用户操作，production 模式拒绝启动。

## 后续事项

直接 SQL 写入可能破坏逻辑引用，运维时需限制写权限并检查数据完整性。后续表的关系和约束分别设计。

0.3.0 已接入组织和角色权限，见 [ADR 0003](0003-identity.md)。production 启动保护保留到 M7 发布验收。
