# ADR 0001：本地开发基线

日期：2026-10-08。状态：已用于本地骨架；生产选型、组织审批及远程设置尚未完成。

## 决策

- 建立独立 `crop-digital-twin` 仓库，不移动已有 `wofost_lai_edge`。单仓库便于联动需求、契约、前后端与算法版本。
- Python 3.12 + uv workspace 管理后端和算法包；Vue + TypeScript + Vite 管理前端。Node 基线 24.19.0，锁文件纳入版本控制。
- Python/SQL 使用 snake_case、TypeScript 使用 camelCase，组件与类使用 PascalCase。这是对通用小驼峰规范的语言适配，以避免违背 Python/SQL 工具习惯。
- 当前 API 使用 GET，后续业务接口使用 GET/POST；其他方法需记录新的明确决策。
- 空仓库首个骨架提交建立在功能分支，再创建 master/develop/test/release_20261008 指针。后续从 release 建功能分支。此初始化特例不代表已完成正式发布或评审。

## 未决事项

- 远程分支保护、代码评审人、生产基础设施与外部服务授权。
- 原设计字典提出物理外键，与组织仅逻辑外键规则存在差异；当前不生成迁移。建表前记录决策及完整性保障方案。
- 作物/地区/品种参数、地图/天气供应商、影像传感器/格式、校准算法和精度阈值。

不将保留目录、设计图或依赖安装视为业务实现；不编造审批、备份、评审和试验历史。
