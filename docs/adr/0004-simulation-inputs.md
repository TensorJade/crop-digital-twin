# ADR 0004：先建立可追溯的模拟输入

2026-10-08。M3 分为输入与引擎两个子模块。本次 M3.1 交付真实导入/持久化/检查/快照链路，M3.2 再运行 PCSE。没有当地参数和实测资料时不默认选一个水稻品种，也不使用旧项目的演示曲线。

三种明确类型的不可变资料共用 input_assets 表，与季节快照表组成一个高内聚输入模块，不增加通用 CRUD 框架、任务队列或微服务。复用 M2 组织、会话、写角色和审计。JSON/CSV 是数据而非可执行配置；来源引用只记录，不触发网络读取。

crop_engine 此阶段只做纯输入校验与单位转换，不依赖 HTTP/SQL，不安装尚未运行的 PCSE。已核对 PCSE6.0.13、EUPL 许可和默认导入会建立用户目录/演示库的行为；实际接入时需要隔离这些副作用，禁止以默认演示库作为应用数据。第三方参数仓库未查得统一许可文件，因此不把远程参数直接打包成产品默认值。

静态完整不等于可运行或农艺验证。出苗与移栽语义、水田灌排、纯氮量、天气来源与当地参数在 M3.2 明确后才启用对应模式。M3 不在本次标记完成。
