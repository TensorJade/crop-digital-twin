# ADR 0004：输入资料与快照

日期：2026-10-08。模块：M3.1。

M3 先实现资料导入、检查和输入快照，再接入 PCSE。具体地区和参数未确定时，不预置水稻品种，也不使用旧项目演示曲线。

土壤、品种和天气共用 input_assets，与 simulation_inputs 组成输入模块。资料和快照只追加，复用组织、会话、角色及审计。JSON/CSV 按明确类型校验，来源引用用于记录，暂不自动联网获取。

crop_engine 此阶段只处理输入和单位，无 HTTP/SQL 依赖，PCSE 执行留到 M3.2。已核对 PCSE 6.0.13 的 EUPL 许可和默认用户目录、演示库初始化行为，实际适配时使用隔离进程。官方参数仓库未找到统一许可文件，因此未打包为默认参数。

静态检查、模型运行和当地农艺验证分别记录。出苗、移栽、水田灌排、纯氮量及参数适用性在对应模型中处理，M3 整体继续开发。
