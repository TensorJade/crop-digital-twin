# ADR 0003：最小组织与会话授权

2026-10-08。M2 使用 SQL 会话，不加入 JWT、Redis、外部身份供应商或通用权限框架。账号对应一个组织，角色 owner/operator/viewer，共享组织内地块；具体地块单独授权矩阵留待确有需求时扩展。

采用 Argon2id 依赖处理密码，随机令牌摘要和会话 CSRF 防护自行维护业务表；不引入第三方自带用户数据库或外部数据服务。新依赖的用途仅为密码哈希，不传输账号或密码。

旧地块不隐式归属；显式初始化操作可接收未归属的旧地块。账户停用、会话撤销、农田写入和审计在 SQL 事务内检查。生产启动仍关闭，避免未验证代理与运维时开放服务。

本决策限定 M2 的开发范围，不代表已有组织审批、人工评审或公开部署。后续权限扩展需迁移现有组织归属，不能删除旧农田事实。
