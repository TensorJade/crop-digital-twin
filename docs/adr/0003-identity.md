# ADR 0003：组织权限与 SQL 会话

日期：2026-10-08。模块：M2。

账号属于一个组织，组织内共享地块，角色为 owner、operator、viewer。逐成员地块授权在需要时再扩展，现阶段使用 SQL 会话，不增加 JWT、Redis、外部身份服务或通用权限框架。

密码由 Argon2id 库处理，SQL 保存随机会话令牌的摘要和会话绑定的 CSRF。账户停用、会话撤销、农田写入及审计在事务内检查。

旧地块保持原记录，只有显式初始化接收时才归属新组织。权限扩展时保留已有组织关系和农田数据。

HTTPS、代理和运维验收在发布前完成，当前 production 启动保护保留。
