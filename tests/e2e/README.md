# 浏览器测试

测试位于 frontend/tests/e2e 的 farm、identity、simulation、growth、weather.spec.ts。Playwright 启动前端、API、独立 worker 和已迁移的临时数据库。Windows 入口为 scripts/check-e2e.ps1，CI 使用 Chromium。

| 编号 | 检查内容 |
|---|---|
| 1 | 地块、种植季、灌溉、换算、修订、刷新、结束及下一季 |
| 2 | 地块和种植季读取失败后重试 |
| 3 | 切换地块时忽略旧请求的延迟响应 |
| 4 | 农田桌面及 390px 手机布局，浏览器错误 |
| 5 | 管理员建只读成员、查看审计、角色和页面布局 |
| 6 | 改密码撤销会话，旧密码失败、新密码登录 |
| 7 | 两组织农田列表隔离 |
| 8 | 停用撤销会话，重新启用后登录 |
| 9 | 伪造代理头不能绕过登录失败限制 |
| 10 | 资料导入、错误 CSV 重试、缺测报告、快照和下载核验 |
| 11 | 只读成员查看和下载输入历史 |
| 12 | PCSE 15 日计算、曲线、日期、下载核验和历史 |
| 13 | 只读成员查看和下载结果，无计算入口 |
| 14 | 天气失败重试、预览、站点目录、CSV、来源保存和两日计算 |

辅助 API 使用独立 Cookie 上下文登录并获取 CSRF。启动器先检查 test 环境和 OS 临时路径，账号只创建在临时数据库，结束时回收自己的进程。代理头测试使用另一回环来源，避免影响其他登录流程。

天气流程使用自有合成小时响应和目录，在页面标记为软件测试资料，不访问 NASA/NOAA；计算使用 worker 和 PCSE，结果检查 weather_method 来源及哈希。公网请求另行检查。

桌面和手机截图、失败 trace、下载文件放在忽略的 runtime / test-results。当前流程检查软件行为，水田精度、遥感、容量和发布验收在对应模块完成。
