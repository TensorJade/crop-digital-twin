# 端到端验收

M1 浏览器测试位于 frontend/tests/e2e/farm.spec.ts。Playwright 自动启动前端、真实 API 和已迁移临时数据库；Windows 入口 scripts/check-e2e.ps1，CI 使用 Chromium。

- 地块/种植季 → 灌溉 → 单位换算 → 修正/旧版 → 刷新 → 结束季节 → 下一季。
- 地块与种植季读取故障后可重试恢复。
- 切换地块时旧请求延迟返回不替换当前种植季。
- 检查浏览器异常；截图检查桌面与 390px 手机布局、无横向溢出。

使用测试名称和隔离数据库，不写用户运行数据库。输出在忽略的 test-results/、runtime/。模拟、遥感链路实现后再补业务验收；当前无科学精度、生产性能或权限验收。
